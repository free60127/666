# 外院知识分享站 · GitHub Pages 上传包

这是截至 2026 年 8 月 17 日的当前网页进度版。将本文件夹内的全部文件和目录上传到 GitHub 仓库的 Pages 发布目录即可使用，入口为 `index.html`。

当前包含：

- 思政系列、计算机系列题库、模拟卷、错题本与 A4 PDF 导出。
- 专业课中的翻译句子、改写句子。
- 英语系基英 1—4 当前题库预览：词汇、选词填空、汉译英。
- 英语系泛读 1—4 当前题库预览：单词与填空练习。
- 通用课程目录：语法（通用）、综英系列（商翻）。
- 专四、专八背单词第一版，学习进度保存在浏览器本机。
- 电子教材、英语/俄语/日语考证资料、计算机实操、赞助与打印小店图片。
- 第三方项目作者与许可证声明：`THIRD_PARTY_NOTICES.md`。

## GitHub Pages 部署

1. 上传本文件夹里面的内容，不要只上传外层文件夹。
2. 在仓库 Settings → Pages 中选择对应分支和目录。
3. 保留 `.nojekyll`、中文目录、图片和所有 JavaScript/CSS 文件。
4. 更新后若浏览器仍显示旧页面，可强制刷新或清理该站点缓存。

用户学习进度、错题本和背单词记录保存在浏览器 `localStorage`；清理浏览器站点数据后会被清空。
