# 思政刷题 H5 版

将整个 `H5` 文件夹上传到任意静态网站托管服务即可使用。

- 入口文件：`index.html`
- 所有题库数据：`data.js`
- 用户进度、错题本、模拟卷保存在用户浏览器本地；清除浏览器站点数据会清空进度。
- 若题库有更新，在本文件夹中执行 `node build-data.js` 重新生成 `data.js`，然后重新上传整个文件夹。

## 可直接发送的单文件版

运行 `node build-standalone.js` 后会生成 `思政刷题-单文件离线版.html`。该文件已内嵌题库、样式与交互逻辑，可单独发送给别人；对方下载后用浏览器打开即可使用。

手机用户可直接扫码或点击网页链接使用；在浏览器菜单中选择“添加到主屏幕”即可像 App 一样打开。
